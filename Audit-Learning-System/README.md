## The big picture: how the pieces connect

Auditing is **checking that a company's financial statements are true and fair**. To do that well, you need three layers of skill:

```
        ┌─────────────────────────────────────────────┐
        │  LAYER 3 — AUDIT (AA)                         │
        │  Risk, evidence, sampling, procedures,        │  ← your job
        │  documentation, the audit report              │
        └─────────────────────────────────────────────┘
                          ▲ built on
        ┌─────────────────────────────────────────────┐
        │  LAYER 2 — REPORTING & ANALYSIS               │
        │  FR (IFRS standards) · FM (finance/ratios)    │  ← what you audit
        │  PM (performance) · MA (costing/budgets)      │
        └─────────────────────────────────────────────┘
                          ▲ built on
        ┌─────────────────────────────────────────────┐
        │  LAYER 1 — FOUNDATION                         │
        │  FA — double entry, ledgers, trial balance,   │  ← the language
        │  the financial statements                     │
        └─────────────────────────────────────────────┘

        Running through ALL layers: EXCEL + AUDIT SOFTWARE
        (how the work actually gets done day to day)
```

**Plain English:**
- **FA** teaches you the language (debits, credits, how a balance sheet is built).
- **MA / PM** teach you how managers use numbers internally (costs, budgets, performance).
- **FR** teaches you the rules companies must follow when publishing accounts (IFRS).
- **FM** teaches you the finance side (cash, investment decisions, ratios).
- **AA** teaches you how to *check* all of the above is correct — your actual job.
- **Excel + tools** are how you execute every task quickly and accurately.

## A note on ACCA itself

The papers in this system map to the **ACCA Qualification** (Association of Chartered Certified Accountants):

- **Applied Knowledge level:** FA (Financial Accounting), MA (Management Accounting) — *plus BT, Business & Technology, which is also part of this level.*
- **Applied Skills level:** PM, FR, FM, AA — *plus LW (Law) and TX (Tax).*

You can study the knowledge here for free, but to get the **ACCA letters after your name** you must register with ACCA and pass the official exams. See `Resources/Courses-and-Certifications.md` for exact steps, fees, and exam booking.

> **Tip for HLB:** Many audit firms sponsor or partly fund ACCA exams for staff who pass probation. Ask your manager or HR about the firm's ACCA support policy — it's a common benefit and a great reason to perform well in these first 2 months.

## How to study so it actually sticks

1. **Learn → Do → Teach.** Read a concept, do an exercise on it, then explain it out loud as if teaching someone. If you can't explain it simply, you don't know it yet.
2. **Excel daily.** Even 20 minutes of practice beats a 3-hour weekend cram. Muscle memory matters.
3. **Connect theory to your real engagements.** When you're given a task at work, find which file in this system covers it, and read that section the same evening.
4. **Keep an error log.** Every mistake a senior corrects → write it down → review weekly. This is the single fastest way to look like you're improving.
5. **Don't fake understanding.** If a reviewer asks something you don't know, say "I'm not sure, I'll check and confirm." That builds more trust than guessing.
